# AI 同声翻译 · Live Translator（MVP）

在线地址：https://wyc77209-source.github.io/ai-translator/

中↔英双向实时对话翻译。纯静态网页，无后端、无密钥入库。

## 怎么用
1. 你用手机打开网页（Chrome / Safari），默认「我说中文」。
2. 对方用手机扫二维码，浏览器直接打开，无需安装，默认「I speak EN」。
3. 双方各自点麦克风说话：
   - 说话过程中的**预测/中间结果只上字幕**（虚线气泡）；
   - 句子确认后才翻译定稿，并在**对方手机上用 TTS 朗读**（猜测只上字幕，不上耳朵）。
4. 没人扫码时是单机模式：译文在本机朗读。

## 技术
- 语音识别 / 朗读：浏览器 Web Speech API（SpeechRecognition + speechSynthesis）。
- 翻译：⚙︎ 设置里填你自己的 OpenAI Key（只存在本机 localStorage，用 gpt-4o-mini）→ 否则免费 Google 网页翻译接口 → 再否则 MyMemory。
- 双端同步：优先 WebRTC（PeerJS 公共信令）；连不上时自动走 ntfy.sh 公共中继（随机房间名；中间结果限流 1.5 秒一条）。

## v2 新增
- **端到端加密**：二维码链接里 `#k=` 是 AES-GCM 密钥（URL 片段不会发给任何服务器）。走 ntfy 中继的所有消息都是密文；WebRTC 本身是 DTLS 加密。没有密钥的链接会提示重新扫码。
- **延迟显示**：每条对方的句子右下角显示 ⏱，从说话方识别定稿到译文出现在本机的时间（已用握手估算两台手机的时钟差）；自己的句子显示本机翻译耗时。
- **术语表**：⚙︎ 里每行写 `中文=English`（如 `交期=lead time`），双向生效；OpenAI 模式写进提示词，免费模式先替换术语再翻译。
- **导出**：右上角 ⤓ 下载对话 txt。
- **稳健性**：每个翻译引擎 6 秒超时、失败重试（退避 0.4s/1.2s），遇到 429/额度用完 30 秒内跳过该引擎；全部失败时气泡里写清楚是哪个引擎、什么错误。

## v3 新增
- 房间和密钥保存在本机，刷新后二维码不变；「新房间」按钮换新房间和新密钥（已连接时点状态标签可重新显示二维码）。
- 可安装到主屏（PWA）；离线也能打开界面（联网时始终取最新版本，不会卡在旧版）。
- 术语预设：展会/CES、工厂审核、日常（⚙︎ 里添加，可再编辑）。
- 模式切换：🔁 自动（点一下开始/停止）或 ✋ 按住说；录音时保持屏幕常亮（支持 Wake Lock 的浏览器）。

## 已知限制
- 语音识别需 Chrome（安卓/桌面）或 iOS Safari 14.5+；Firefox 不支持。
- 免费翻译接口不保证稳定，有限流；正式用建议填 Key。
- ntfy.sh 中继是公开服务，但内容已加密；房间名和消息时间仍对中继可见。
